# Plugin Marketplace Sync, Cache & Offline Import v1

This additive host-services milestone provides deterministic catalog refresh planning, ETag-based not-modified handling, trusted offline catalog use, update detection, package cache validation and exact-identity offline `.digitorfx` import.

The Digitor app owns networking, storage, commercial entitlement and export authorization. Free users may import and preview paid plugins; the app does not submit paid export work for unauthorized users. DigitorEngine only validates identities and processes app-authorized requests.

The render graph, shader compiler, shader reflection, pipeline cache, Primary Wheels, GPU backend selection, CPU fallback policy, preview runtime, export runtime and existing filter/effect/transition algorithms are unchanged.
