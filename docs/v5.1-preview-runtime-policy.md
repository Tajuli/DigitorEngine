# v5.1 Preview Runtime Policy

Preview performance settings are execution policy only. They must not modify the immutable color graph, operation order, serialized parameters, working color metadata, or export source selection.

## Adaptive quality

Adaptive preview starts at Half quality. After a stable window of slow frames it demotes to Quarter. After a stable window of fast frames it promotes toward Full. A quality transition invalidates preview caches so frames from different execution resolutions cannot be reused accidentally.

## Dropped frames

Interactive playback may discard requests older than the newest requested frame. This skips presentation work only; it never changes frame numbering, color parameters, source timing, or export behavior. The Never policy remains available for frame-by-frame inspection.

## Qualifier sampling

A preview eyedropper coordinate is mapped through pixel centers into the original media dimensions. HSL sampling can therefore request the original-resolution source pixel rather than sampling a compressed or downscaled preview pixel.

## Export contract

Each export frame contract records the requested full output dimensions, original source identity, and immutable color-graph identity. Export rejects any selected source that is not classified as Original.
