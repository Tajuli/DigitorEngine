# v5.50.0 — Broadcast Monitoring and Color Matching

This milestone adds production broadcast-legality analysis and deterministic color-matching orchestration without rewriting the existing grading, color-management, HDR, OCIO, ICC/display, LUT, GPU scopes, playback, or export systems.

## Broadcast monitoring

- Rec.601, Rec.709, Rec.2020 SDR, PQ, and HLG policy identities
- full-range and legal-range analysis
- luma, chroma, gamut, and non-finite excursion detection
- warning-mask generation
- minimum, maximum, average luma and peak-nits reporting
- action-safe, title-safe, and custom safe-area validation
- deterministic telemetry and diagnostics

## Color matching

- neutral/statistical/reference-frame matching
- chart-patch matching contract
- deterministic channel gain and transform representation
- alpha preservation
- optional luminance preservation
- bounded strength control
- before/after error and confidence reporting
- reusable transform application for preview and export

## Qualification boundary

Automated tests verify legality analysis, warning masks, invalid safe-area rejection, reference matching, chart matching, alpha preservation, error improvement, and telemetry. Final broadcast certification still requires calibrated SDI/HDMI monitoring, approved legalizer behavior, broadcaster-specific test patterns, and physical output-device qualification.
