# v5.49.0 — Professional LUT + GPU Scopes

This milestone extends the existing LUT and scope systems without rewriting them.

## Professional LUT layer

- `.cube`, `.3dl`, `.csp`, `.spi1d`, and `.spi3d` identities
- strict structural and numeric validation
- 1D and 3D LUT inventories with stable IDs and content hashes
- nearest, linear, and tetrahedral interpolation policies
- FP16/FP32 GPU resource contracts for D3D12, Vulkan, Metal, and OpenGL ES
- bounded GPU-resource cache with deterministic eviction and release callbacks
- explicit GPU-required behavior; no silent CPU fallback when GPU is mandatory
- alpha preservation and non-finite input rejection

## Production GPU scopes

The existing professional color-management scope implementation remains the deterministic CPU reference. This milestone adds a production GPU dispatch boundary for waveform, RGB parade, vectorscope, histograms, CIE xy, false color, and HDR-scale results. A caller may require GPU execution or permit the existing CPU reference path.

## Qualification boundary

Automated tests cover LUT loading, CPU interpolation, GPU upload/application, cache reuse, GPU-required failure, scope dispatch, CPU-reference fallback, telemetry, and lifecycle. Backend-native texture allocation, compute kernels, asynchronous readback, and calibrated-device performance remain part of platform qualification.
