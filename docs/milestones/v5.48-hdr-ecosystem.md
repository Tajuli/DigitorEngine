# v5.48.0 — HDR Ecosystem

This milestone extends the existing professional color-management, OCIO, ICC/display, Camera RAW, playback and export systems without rewriting them.

## Added

- HDR10, HLG, HDR10+ and Dolby Vision metadata models
- HDR10+ frame/window validation and generation from frame analysis
- Dolby Vision profile/level/trim abstraction
- explicit licensed-adapter boundary for Dolby Vision RPU packaging
- static and dynamic metadata transport contracts
- frame luminance analysis, percentiles, MaxCLL and MaxFALL
- BT.2390-like, perceptual, scene-adaptive and display-adaptive tone mapping
- reference-white, source-peak and display-peak policies
- alpha preservation, finite-value validation and telemetry
- deterministic qualification tests

## Licensing boundary

Dolby Vision bitstream/RPU generation requires a licensed implementation. DigitorEngine exposes a strict adapter contract and returns `DIGITOR_RESULT_BACKEND_UNAVAILABLE` when no licensed adapter is installed. It does not emulate or falsely advertise proprietary packaging.

## Qualification boundary

Automated tests cover metadata validation, analysis, tone mapping, HDR10+ generation, packet transport selection, Dolby Vision adapter enforcement and telemetry. Final HDR certification requires calibrated displays, compliant encoders/muxers, licensed Dolby tooling where applicable and representative delivery-device testing.
