# v5.47.0 — Camera RAW Foundation

This milestone adds a vendor-neutral Camera RAW integration layer without rewriting the existing professional import, media decode, color-management, OCIO, ICC/display, playback, node, or export systems.

## Included

- RAW codec inventory for CinemaDNG, Blackmagic RAW, REDCODE RAW, ARRIRAW, Canon RAW, Sony RAW, ProRes RAW, and vendor-defined formats
- vendor SDK adapter registration and capability discovery
- metadata-only probing
- camera, sensor, timecode, reel, bit-depth, frame-rate, ISO, white-balance, native gamut, and native transfer metadata
- draft, half, and full debayer quality requests
- camera, auto-neutral, and manual white-balance policy
- ISO, exposure, highlight recovery, shadow recovery, black-level, and saturation controls
- camera-native, log, and scene-linear output contracts
- GPU-resident native-surface output and strict `require_gpu` behavior
- validated RGBA32F CPU fallback when explicitly allowed
- random-access seek contract
- bounded decoded-frame cache with invalidation
- adapter and decode telemetry
- deterministic qualification tests

## Vendor SDK boundary

BRAW, RED, ARRIRAW, Canon RAW, Sony RAW, and ProRes RAW implementations require their respective SDKs, licenses, supported operating systems, and redistributable components. DigitorEngine does not imitate proprietary bitstream decoders or silently claim support when an SDK adapter is unavailable. A platform host registers an adapter whose callbacks probe, open, seek, decode, and close the vendor media.

## Pipeline

```text
Professional Import asset
  -> CameraRawEngine probe/open
  -> vendor SDK adapter
  -> debayer and RAW controls
  -> GPU native surface or validated RGBA32F
  -> existing OCIO/professional color pipeline
  -> existing playback, scopes, and export
```

## Qualification boundary

Automated tests validate adapter registration, metadata consistency, decode-setting ranges, GPU-required enforcement, CPU/GPU frame contracts, frame caching, seek invalidation, telemetry, and lifecycle behavior. Final vendor-format qualification requires licensed SDKs, representative camera clips, and physical GPU/device testing.
