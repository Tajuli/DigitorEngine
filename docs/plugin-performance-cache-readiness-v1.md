# Plugin Performance, Pipeline Warmup and Cache Readiness v1

This additive milestone qualifies code-free filter, effect and transition packages against cold compile, warm pipeline, frame-time, transient-memory and cache-hit budgets.

The Digitor app may use the report to pre-warm pipelines before playback or export. Free/paid state and export authorization remain app-owned.

Preview and authorized export must use the same exact plugin identity and processing contract. The existing Render Graph, Shader Compiler, Shader Reflection, Pipeline Cache, Primary Wheels, backend selection and CPU fallback policy are not modified.
