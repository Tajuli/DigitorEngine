# Plugin Catalog Metadata & Compatibility v1

This additive marketplace layer lets built-in and website-imported filters, effects and transitions describe category, tags, thumbnail, preview media and localized names/descriptions without changing engine processing code.

Compatibility is evaluated before import or activation using the minimum DigitorEngine version, supported GPU backends, compute/FP16 requirements and supported pixel formats. The host receives a specific diagnostic instead of attempting an incompatible runtime dispatch.

The metadata contains no free/paid, purchase, subscription, preview-right or export-right policy. Digitor app remains authoritative for commercial access.

This milestone does not redesign or replace the render graph, shader compiler, shader reflection, pipeline cache, Primary Wheels, GPU backend selection, CPU fallback policy, preview runtime or export runtime.
