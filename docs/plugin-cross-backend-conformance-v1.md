# Plugin Cross-Backend Conformance v1

This additive qualification contract verifies that code-free filter, effect and transition packages expose equivalent resource bindings, parameter layouts, alpha behavior and deterministic processing across D3D12, Vulkan, Metal and OpenGL ES.

Preview and app-authorized export must resolve the same package identity and backend contract. Commercial entitlement remains owned by the Digitor app.

The contract does not modify Render Graph, Shader Compiler, Shader Reflection, Pipeline Cache, Primary Wheels, backend selection, CPU fallback policy or existing processing algorithms.
