# Plugin Golden-Frame & Real-Media Qualification v1

This additive qualification contract validates code-free filter, effect and transition output without changing DigitorEngine rendering algorithms.

It records exact plugin identity, backend, SDR/HDR transfer function, preview/export digests, channel error, alpha error, color metadata preservation and deterministic output. Release qualification requires coverage for all three plugin kinds and rejects preview/export mismatch, excessive pixel error, alpha drift, missing color metadata and nondeterministic output.

The Digitor app remains responsible for free/paid state and export authorization. The engine only qualifies and processes app-authorized work.
