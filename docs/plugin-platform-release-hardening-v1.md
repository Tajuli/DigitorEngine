# Plugin Platform Release Hardening v1

This additive milestone verifies that the completed code-free filter, effect and transition platform is releasable without changing established rendering behavior.

The readiness report requires all plugin-platform components to be installed, linked and cross-platform qualified; verifies Windows, Android, macOS and iOS lifecycle coverage; enforces signed atomic installation, exact version/hash pinning and preview/export parity; and rejects any release that moves commercial entitlement into DigitorEngine or changes main rendering features.

The Digitor app remains authoritative for free/paid state. Free users may import and preview paid plugins, while paid export requires app authorization before the engine receives processing work.
