# Plugin ABI Compatibility, Upgrade Safety and LTS v1

This additive milestone protects code-free filters, effects and transitions across future DigitorEngine releases.

- ABI, manifest and project schemas negotiate within a stable major generation.
- Exact plugin ID, version and SHA-256 project identity remains authoritative.
- Deprecated fields remain usable until an explicit removal-not-before version.
- Newer schemas require a declared migration instead of silent interpretation.
- Preview and app-authorized export use the same compatibility result.
- Free/paid, purchase, subscription and export permission remain Digitor app responsibilities.
- Render Graph, shader systems, Primary Wheels, backend priority, CPU fallback and existing processing algorithms are unchanged.
