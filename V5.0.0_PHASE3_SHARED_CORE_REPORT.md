## GPU-first invariant

A selected GPU path cannot call the CPU HSL reference and still return success. Backend wrapper methods compare the reference invocation count before and after native execution, clear invalid output, and return an internal error if CPU work is detected.

## Deliberately not claimed in this phase

The production Vulkan, D3D12, Metal, and OpenGL ES overrides are not part of Phase 3. Default backend methods return `DIGITOR_RESULT_UNSUPPORTED` and never silently invoke the CPU reference. The next phase is native Vulkan and D3D12 execution, followed by Metal and OpenGL ES parity.
