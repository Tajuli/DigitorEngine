# DigitorEngine v5.0.0 Phase 5 — Metal and OpenGL ES HSL Qualifier

## Implemented

- Metal pipeline-cache operation and `hsl_qualifier` compute-function selection.
- Metal CPU-source HSL matte execution into a GPU-resident RGBA32F `ProcessedGpuFrame`.
- Metal GPU-source chaining without an intentional host readback/re-upload.
- Metal validation-only matte readback.
- OpenGL ES pipeline-cache operation for HSL Qualifier.
- OpenGL ES CPU-source HSL matte execution using an RGBA32F texture/FBO path.
- OpenGL ES GPU-source chaining using the prior resident texture.
- OpenGL ES validation-only matte readback.
- HSL execution provenance identities and resource-binding evidence for both backends.
- Explicit matte representation: scalar matte replicated to RGB, alpha fixed to 1.0.
