# v5.0.0 Android Embedded SPIR-V Update

## Change

Android Vulkan shaders are now compiled on the Windows/macOS/Linux build host with the `glslc` shipped by the Android NDK and embedded into `digitor_engine` as generated C++ headers.

The Android device no longer invokes DXC, `glslc`, or `spirv-val` at runtime.

Generated variants:

- Primary Wheels texture compute
- Log Wheels texture compute
- HSL Qualifier texture compute
- RGB Curves texture compute
- RGB Curves buffer compute
- Color Pipeline buffer compute

## Production behavior

- Android: embedded build-time SPIR-V only
- Other hosts: existing developer/runtime compiler path remains available
- Missing embedded shader: explicit backend failure; no CPU fallback

## Required device requalification

Rebuild the Android target from a clean `build-android` directory, push the newly linked executable, and rerun on the Android device. The old executable still contains the runtime compiler path.
